Integritetspolicy

Här beskriver vi hur personuppgifter behandlas när du kontaktar Kompass Företag & Samhälle.

Verksamhet under bildande. Erik Mohamed är tills vidare personuppgiftsansvarig för behandlingen som beskrivs på denna sida.

Vilka uppgifter vi behandlar

När du använder kontaktformuläret kan vi behandla namn, e-postadress, telefonnummer, roll, organisation samt de uppgifter du själv lämnar i meddelandet. Skicka inte känsliga personuppgifter via formuläret.

Ändamål och rättslig grund

Uppgifterna används för att ta emot, bedöma och besvara din förfrågan samt för att kunna följa upp en möjlig dialog eller ett uppdrag. Behandlingen grundas på ditt samtycke. Du kan när som helst återkalla samtycket genom att kontakta oss.

Hur uppgifterna hanteras

Formuläret skickas via FormSubmit, som behandlar uppgifterna för att vidarebefordra meddelandet till vår e-post. Uppgifterna delas inte med andra om det inte krävs enligt lag eller är nödvändigt för att hantera din förfrågan.

Lagringstid

Vi sparar uppgifterna så länge de behövs för att hantera och följa upp förfrågan, normalt högst tolv månader. Uppgifter som behöver sparas längre på grund av avtal eller lagkrav hanteras enligt tillämpliga regler.

Dina rättigheter

Du har rätt att begära information om vilka personuppgifter vi behandlar om dig och att begära rättelse eller radering. Du kan även begära begränsning, invända mot viss behandling och i tillämpliga fall få ut dina uppgifter. Kontakta oss via e-post för att använda dina rättigheter.

Klagomål

Om du anser att dina personuppgifter behandlas felaktigt kan du lämna klagomål till Integritetsskyddsmyndigheten (IMY).

Ändringar

Policyn kan uppdateras när verksamheten får en registrerad juridisk person eller när behandlingen förändras. Senast uppdaterad: 16 september 2026.
